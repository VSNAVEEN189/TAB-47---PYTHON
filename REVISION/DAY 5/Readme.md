# Python Fundamentals Practice 🐍

## Overview

My Python learning journey, I practiced three beginner-level problems to strengthen my understanding of Python fundamentals, logical operators, conditional statements, and problem-solving.

The goal was not just to write code but to understand the logic behind each problem and handle different input scenarios.

## Problems Solved

### 1. Student Scholarship Eligibility Checker

**Objective:** Check whether a student qualifies for a scholarship based on three conditions.

**Eligibility Criteria:**
- Marks must be 85 or above.
- Attendance must be 75% or above.
- No pending fees.

**Concepts Used:**
- `input()`
- Type conversion using `float()`
- Comparison operators
- Logical operator (`and`)
- Boolean values
- String comparison

**Key Learning:** A non-empty string such as `"no"` is considered `True` in Python. Explicit comparison is necessary when checking a user's yes/no response.

### 2. Student Result Calculator

**Objective:** Calculate the total marks, average marks, and pass/fail status of a student.

**Conditions:**
- Three subjects: Mathematics, Science, and English.
- A student must score at least 40 marks in every subject to pass.
- If even one subject has marks below 40, the student fails.

**Concepts Used:**
- Arithmetic operators (`+`, `/`)
- Comparison operators (`>=`)
- Logical operators (`and`)
- Conditional statements (`if-else`)
- Formatted output

**Key Learning:** A good overall average does not guarantee a pass. Every subject must meet the minimum passing criteria.

### 3. Student Grade Calculator

**Objective:** Calculate total marks, average marks, pass/fail status, and the final grade.

**Grading Criteria:**

| Average Marks | Grade |
|---|---|
| 90 and above | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| Below 60 | D |

**Additional Conditions:**
- Minimum passing marks in every subject: 40.
- If any subject has less than 40 marks, the student receives an F grade.
- Marks must be between 0 and 100.
- Invalid marks should be rejected.

**Concepts Used:**
- Nested `if-else` statements
- `if`, `elif`, and `else`
- Logical operators (`and`, `or`)
- Input validation
- F-string formatting (`:.2f`)
- Debugging

**Key Learning:** The order of conditions matters. A student must pass the individual subject requirements before the average-based grade is calculated.
