# Python Operators – Practice Problems 

## Description
Practiced Python operators through five real-world problems to strengthen logical thinking, calculations, and problem-solving skills.

## Problems Solved

### 1. Electricity Bill Calculator
- Calculated electricity bills based on units consumed.
- Practiced arithmetic operators (`*`).
- Used input conversion with `int()`.

### 2. Expense Comparison
- Compared two expense amounts.
- Practiced comparison operators (`>`, `==`, `<=`).
- Understood Boolean results (`True` / `False`).

### 3. Discount Eligibility Checker
- Checked customer eligibility based on bill amount and membership.
- Practiced logical operator (`and`).
- Used comparison operators and Boolean conditions.

### 4. Wallet Balance Tracker
- Updated wallet balance through additions, deductions, multiplication, and division.
- Practiced assignment operators (`+=`, `-=`, `*=`, `/=`).

### 5. Number Analysis
- Calculated square and cube of a number.
- Found quotient and remainder.
- Checked whether a number is even or odd.
- Practiced (`**`, `//`, `%`, `==`).

## Concepts Practiced
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Assignment Operators 
- Type Conversion
- Boolean Values
- Basic Problem-Solving and Debugging

## Key Learning
Learned how different operators work together to solve practical problems. Also improved debugging skills by identifying incorrect variable usage and logical conditions.
