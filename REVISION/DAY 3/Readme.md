# Employee Salary Calculator 

## Description
A simple Python payroll calculator that calculates an employee's final salary based on basic salary, bonus percentage, and tax percentage.

## Concepts Practiced
- User input using input()
- Type conversion using float()
- Arithmetic operators
- Percentage calculations
- Formatted output using f-strings
- Checking data types using type()

## How It Works
1. Accepts basic salary, bonus percentage, and tax percentage.
2. Converts all inputs into float values.
3. Calculates the bonus amount.
4. Adds the bonus to the basic salary.
5. Calculates tax on the updated salary.
6. Deducts tax to calculate the final salary.
7. Displays all calculated amounts up to two decimal places.

## Sample Calculation
| Description | Amount |
|---|---:|
