# Shopping Bill Calculator 

## Description
A simple Python program that calculates the total shopping bill based on item price, quantity, and discount percentage.

## Concepts Practiced
- User input using input()
- Type conversion using inint() and float()
- Arithmetic operators
- Calculating percentage discounts
- Displaying calculated results

## How It Works
1 Accepts the item price, quantity, and discount percentage.
2 Converts inputs into numeric values.
3 Calculates the total price.
4 Calculates the discount amount.
5 Deducts the discount from the total bill.
6 Displays the final amount.

## Sample Calculation
| Item | Value |
|---|---:|
| Price | ₹66 |
| Quantity | 22 |
| Discount | 11% |
| Total Price | ₹1,452 |
| Discount Amount | ₹159.72 |
| Final Bill | ₹1,292.28 |

Practiced type conversion and arithmetic operations by building a practical shopping bill calculator.
