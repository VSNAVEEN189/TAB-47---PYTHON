# Day 6 – Student Discount Calculator 🐍

## Overview
Built a Python-based discount calculator that applies discounts based on purchase amount and generates a formatted customer receipt.

## Discount Criteria

| Purchase Amount | Discount |
|---|---:|
| Below ₹1,000 | 0% |
| ₹1,000–₹4,999 | 5% |
| ₹5,000–₹9,999 | 10% |
| ₹10,000 and above | 15% |

## Concepts Practiced
- User input and type conversion
- `if-elif-else` conditions
- Comparison and arithmetic operators
- Input validation
- F-string formatting

## Sample Output

```text
Customer: Naveen
Purchase Amount: ₹40,000.00
Discount: 15% (₹6,000.00)
Final Amount: ₹34,000.00
```

## Key Learnings
- Converting requirements into logical conditions.
- Applying percentage-based calculations.
- Validating inputs and formatting output.
